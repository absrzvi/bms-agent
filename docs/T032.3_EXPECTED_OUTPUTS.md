## ❌ What NOT to Show (Known Failures)

### Don't Demo These:

**A1: "Show me BMS network architecture requirements"**
- Returns 0 results (content gap)

**E1: "HUMR-FOR-005" (alone)**
- May answer previous question (context bleeding)
- Use new chat or full description

**E3: "forms" (single word)**
- Only returns 3 HUMR forms (poor diversity)
- Use specific queries like "HUMR forms" or "procurement forms"

**B1: "EN45545 requirements"**
- Returns company policies, not hardware specs
- Confusing unless you clarify "internal EN45545 compliance"
