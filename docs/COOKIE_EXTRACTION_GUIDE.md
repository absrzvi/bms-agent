# Cookie Extraction Guide for SharePoint Downloads

## Overview

This guide shows you how to extract browser cookies to authenticate with SharePoint from the server, avoiding complex M365/OAuth authentication.

**Time Required**: 2-3 minutes  
**Difficulty**: Easy

---

## 🍪 Method 1: Browser Extension (Recommended)

### Step 1: Install Extension

**Chrome/Edge**:
1. Go to: https://chrome.google.com/webstore
2. Search for: **"Get cookies.txt LOCALLY"**
3. Click "Add to Chrome/Edge"

**Firefox**:
1. Go to: https://addons.mozilla.org
2. Search for: **"cookies.txt"**
3. Install **"cookies.txt"** extension

### Step 2: Log into SharePoint

1. Open your browser
2. Navigate to: `https://nomadrail.sharepoint.com`
3. Log in with your credentials
4. **Stay logged in** - don't close the tab

### Step 3: Export Cookies

1. Click the extension icon in your browser toolbar
2. Click **"Export"** or **"Export As"**
3. Choose **"Netscape format"** (cookies.txt format)
4. Save the file as: `sharepoint_cookies.txt`

### Step 4: Upload to Server

**Option A: Direct Copy (if you have file access)**
```bash
# Copy to the project directory
cp /path/to/sharepoint_cookies.txt /workspace/001-bms-agent/
```

**Option B: SCP/SFTP**
```bash
# From your local machine
scp sharepoint_cookies.txt user@server:/workspace/001-bms-agent/
```

**Option C: Paste Content**
```bash
# On the server
nano /workspace/001-bms-agent/sharepoint_cookies.txt
# Paste the cookie content
# Save with Ctrl+O, Exit with Ctrl+X
```

## 🍪 Method 2: Manual Cookie Export (No Extension)

### Chrome/Edge

1. Open SharePoint and log in
2. Press `F12` to open Developer Tools
3. Go to **Application** tab
4. In left sidebar, expand **Cookies**
5. Click on `https://nomadrail.sharepoint.com`
6. Right-click on the cookie list
7. Select **"Copy all as cURL"** or export manually

### Firefox

1. Open SharePoint and log in
2. Press `F12` to open Developer Tools
3. Go to **Storage** tab
4. Expand **Cookies**
5. Click on `https://nomadrail.sharepoint.com`
6. Right-click and copy cookies

### Create cookies.txt File

Create a file with this format:
```
# Netscape HTTP Cookie File
# This file was generated by your browser
.sharepoint.com	TRUE	/	TRUE	0	FedAuth	AAABAA...
.sharepoint.com	TRUE	/	TRUE	0	rtFa	AAABAA...
nomadrail.sharepoint.com	FALSE	/	TRUE	0	SPOIDCRL	AAABAA...
```

**Important cookies to include**:
- `FedAuth`
- `rtFa`
- `SPOIDCRL`
- Any cookie with "sharepoint" in the domain

## 🔧 Troubleshooting

### Issue: "Cookies file not found"
**Solution**: 
```bash
# Check the path
ls /workspace/001-bms-agent/sharepoint_cookies.txt

# If missing, create it:
touch /workspace/001-bms-agent/sharepoint_cookies.txt
nano /workspace/001-bms-agent/sharepoint_cookies.txt
# Paste cookies and save
```

### Issue: "HTTP 401: Unauthorized"
**Solution**: Your cookies have expired. Re-export fresh cookies:
1. Log into SharePoint again
2. Export new cookies
3. Replace the old cookies file

### Issue: "Cannot extract filename"
**Solution**: Some URLs may have different formats. The script will skip these and continue.

### Issue: Downloads are slow
**Solution**: Reduce the delay:
```bash
python scripts/download_sharepoint_server.py --delay 1
```

### Issue: "HTTP 429: Too Many Requests"
**Solution**: Increase the delay:
```bash
python scripts/download_sharepoint_server.py --delay 5
```

## 📝 Cookie File Format

Your `sharepoint_cookies.txt` should look like this:

```
# Netscape HTTP Cookie File
# This is a generated file! Do not edit.

.login.microsoftonline.com	TRUE	/	TRUE	1735689600	ESTSAUTH	AAABAA...
.login.microsoftonline.com	TRUE	/	TRUE	1735689600	ESTSAUTHPERSISTENT	AAABAA...
.sharepoint.com	TRUE	/	TRUE	0	FedAuth	77u/PD94bWwgdm...
.sharepoint.com	TRUE	/	TRUE	0	rtFa	AAABAA...
nomadrail.sharepoint.com	FALSE	/	TRUE	0	SPOIDCRL	AAABAA...
```

**Key fields**:
1. Domain (e.g., `.sharepoint.com`)
2. Include subdomains (TRUE/FALSE)
3. Path (`/`)
4. Secure (TRUE/FALSE)
5. Expiration timestamp
6. Cookie name
7. Cookie value

---

## ⏱️ Cookie Expiration

**Important**: SharePoint cookies typically expire after:
- **Session cookies**: When you close the browser
- **Persistent cookies**: 1-7 days

**Best Practice**:
- Export fresh cookies before each download session
- If downloads fail with 401 errors, re-export cookies

---

## 🔒 Security Notes

1. **Keep cookies private**: They grant access to your SharePoint account
2. **Don't commit to Git**: Add `sharepoint_cookies.txt` to `.gitignore`
3. **Delete after use**: Remove the cookies file when done
4. **Use on trusted servers only**: Don't share cookies with others

```bash
# Add to .gitignore
echo "sharepoint_cookies.txt" >> .gitignore

# Delete cookies after download
rm /workspace/001-bms-agent/sharepoint_cookies.txt
```
