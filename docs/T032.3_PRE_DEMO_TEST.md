# T032.3: Pre-Demo Testing Checklist

**Run these tests 30 minutes before your demo to verify everything works.**

---

## 🔧 System Check (5 minutes)

### OpenWebUI Status
```bash
# Check if OpenWebUI is running
curl http://localhost:3000/health

# Expected: 200 OK
```

- [ ] OpenWebUI accessible at http://localhost:3000
- [ ] Can create new chat
- [ ] BMS Agent tool visible in tools list
- [ ] Tool version shows v3.1 or "Enhanced v3.0"

### BMS API Status
```bash
# Check BMS API
curl http://localhost:8000/health

# Expected: {"status": "healthy", "services": {"qdrant": "connected"}}
```

- [ ] BMS API running
- [ ] Qdrant connected
- [ ] No error messages in logs

## 🤖 Agentic Tests (10 minutes)

### Test 4: Form Filling
**Prompt**: `Show me a filled example of a vendor evaluation form`

**Expected**:
- Searches for vendor form
- Generates filled example
- Includes realistic company (Siemens or Bombardier)
- Shows scores 1-5 with stars
- Provides recommendation
- Lists next steps

**If fails**:
- LLM not generating → Check model loaded (mistral-nemo)
- Generic output → Prompt needs more context
- No results → Search failed first

**Status**: ☐ Pass ☐ Fail

---

### Test 5: Workflow Guidance
**Prompt**: `Walk me through railway engineer onboarding`

**Expected**:
- Multiple phases shown (3-5 phases)
- 10+ forms listed
- Forms from multiple departments (HUMR, QHSE, ENGI)
- Timeline estimates
- Responsibilities assigned

**If fails**:
- Only search results → LLM not understanding intent
- Single form → Not synthesizing workflow
- Too generic → Add more context to prompt

**Status**: ☐ Pass ☐ Fail

---

### Test 6: Multi-Document Synthesis
**Prompt**: `Compare ENGI and QHSE procurement processes`

**Expected**:
- Comparison table
- Different thresholds (€50k vs €25k)
- Timeline differences
- 4-6 documents cited
- Recommendations provided

**Status**: ☐ Pass ☐ Fail

---

## 📤 File Upload Test (Optional - 5 minutes)

### Test 7: Invoice Processing

**Setup**: Create test invoice PDF with:
```
Vendor: Bombardier Transportation
Invoice #: INV-2025-TEST-001
Date: 2025-10-01
Amount: €45,320.00
Items: Brake components (50 units)
```

**Prompt**: `[Upload] Extract invoice and fill procurement form`

**Expected**:
- Extracts vendor, amount, date, items
- Finds BMS-PROJ-FOR-002
- Shows auto-filled fields (✅)
- Shows manual fields (⚠️)
- 60-80% auto-fill rate
- Approval routing shown

**If fails**:
- Upload not working → Check OpenWebUI file upload settings
- No extraction → LLM not processing file
- No form → Search component failed

**Status**: ☐ Pass ☐ Fail ☐ Skip (if no file)

## 📊 Performance Check (5 minutes)

### Response Time Test
Run each query and measure time:

- [ ] `GDPR compliance` → ____ seconds (target: <5s)
- [ ] `procurement forms` → ____ seconds (target: <7s)
- [ ] `vendor selection` → ____ seconds (target: <5s)

## 🔄 Context Bleeding Test (3 minutes)

### Test E1: Context Isolation
**Purpose**: Verify context bleeding issue

**Step 1**: In Chat 1, ask: `What are KPIs for BMS?`  
**Step 2**: In SAME chat, ask: `HUMR-FOR-005`

**Expected**: May answer about KPIs (context bleeding)

**Step 3**: In NEW chat, ask: `HUMR-FOR-005`

**Expected**: Should search for HUMR-FOR-005 document

**Learning**: Always use NEW chat for demo scenarios

## 🎬 Final Go/No-Go Decision

**GO if**:
- ✅ All smoke tests pass
- ✅ 5/6 agentic tests pass
- ✅ New formatting visible
- ✅ Response times acceptable (<10s)

**NO-GO if**:
- ❌ Tool showing old format (reload needed)
- ❌ API down or errors
- ❌ >50% tests failing
- ❌ Response times >15 seconds

## 🆘 Quick Fixes

### If Tool Not Showing New Format:
```bash
# 1. Reload in OpenWebUI
Admin Panel → Tools → BMS Agent Search → Refresh

# 2. Clear browser cache
Ctrl+Shift+Delete → Clear cached files

# 3. Restart OpenWebUI (if needed)
docker-compose restart openwebui
```

### If API Slow:
```bash
# Check Qdrant performance
curl http://localhost:6333/collections/bms_documents

# Restart if needed
docker-compose restart qdrant
```

### If LLM Not Responding:
```bash
# Check Ollama
curl http://localhost:11434/api/tags

# Ensure mistral-nemo loaded
ollama run mistral-nemo
```
