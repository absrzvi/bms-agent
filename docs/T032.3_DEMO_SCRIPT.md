# T032.3: BMS Agent Demo Script

**Duration**: 8-10 minutes  
**Date**: 2025-10-05  
**Version**: Complete Edition with All Agentic Scenarios

---

## 🎬 Demo Flow (8 minutes)

### Pre-Demo Checklist
- [ ] OpenWebUI running at http://localhost:3000
- [ ] BMS Search tool v3.1 loaded
- [ ] Screen recorder ready
- [ ] Sample invoice PDF prepared
- [ ] Browser at 110% zoom for visibility

---

## ACT 1: Introduction (60s)

**Script**: "Welcome! Today I'm demonstrating the BMS Agent - our intelligent assistant for navigating Nomad Rail's 600+ documents. It doesn't just search - it guides workflows, fills forms, and analyzes data. Let's see it in action."

---

## ACT 2: Enhanced Retrieval (90s)

**PROMPT**: `Show me GDPR compliance and data protection documents`

**HIGHLIGHT**: Point to ⭐ stars, 📊 percentages, document IDs

**Script**: "Notice the enhanced formatting - star ratings, confidence levels, separated IDs. This addresses user feedback from testing."

---

## ACT 3: Smart Form Filling (120s)

**PROMPT**: `I need to see a completed example of a vendor evaluation form. Show me how it should be filled out with realistic railway procurement data.`

**Script**: "Watch as it searches for the form, understands railway context, and generates realistic example data. This saves hours for new employees."

**Expected**: Agent generates filled form with Siemens Mobility example, scores, recommendations

**HIGHLIGHT**: "Seconds not hours. Realistic details from BMS docs."

---

## ACT 4: Guided Workflow (120s)

**PROMPT**: `I need to onboard a new railway engineer next week. Walk me through the complete onboarding process with all required forms and documents.`

**Script**: "Instead of multiple searches, one question gets a complete multi-phase workflow with forms, timelines, and responsibilities."

**Expected**: 5-phase onboarding plan with 12+ forms across HUMR, QHSE, ENGI

**HIGHLIGHT**: "12 forms across 5 departments, structured timeline"

---

## ACT 5: File Upload Automation (120s)

**PROMPT**: `[Upload invoice PDF] I received this invoice from a vendor. Please extract the key information and fill out the procurement approval form for me.`

**Script**: "The wow factor - upload invoice, get auto-filled form. Watch it extract vendor details, amounts, dates, and fill the procurement form."

**Expected**: 70% auto-filled, 30% flagged for manual input

**HIGHLIGHT**: "70% done automatically. 20 minutes becomes 2 minutes."

---

## ACT 6: Multi-Document Synthesis (90s)

**PROMPT**: `How do procurement approval processes differ between the Engineering department and the QHSE department? Compare thresholds, requirements, and timelines.`

**Script**: "Not just retrieval - analytical synthesis. It compares 6 documents and creates this comparison table."

**Expected**: Table comparing thresholds (€50k vs €25k), timelines, requirements

**HIGHLIGHT**: "6 documents synthesized. 3 hours of analysis in seconds."

---

## ACT 7: Closing (60s)

**Script**: 
"What we've seen:
- ✅ Enhanced retrieval (stars, percentages)
- ✅ Smart form filling (realistic examples)
- ✅ Workflow guidance (multi-step processes)
- ✅ File automation (invoice → form)
- ✅ Intelligent analysis (cross-department comparison)

**Status**: 612 docs, 80% accuracy, 73% test pass rate

**Limitations**: New chat for independent searches, some content gaps

**Next**: First user pilot this week

Questions?"

---

## 🎯 Quick Version (5 minutes)

Skip Acts 4 & 6, show only: Introduction → Retrieval → Form Filling → File Upload → Closing

---

## 📝 Backup Prompts (If Demo Fails)

**If search fails**: `Show me procurement forms for external opportunities`  
**If form filling fails**: `What's in the vendor selection guide?`  
**If file upload unavailable**: Skip to multi-document synthesis

---

## ✨ Key Talking Points

1. **"Seconds not hours"** - for form filling
2. **"12 forms identified"** - for workflow demo
3. **"70% auto-filled"** - for file upload
4. **"6 documents synthesized"** - for analysis
5. **"73% test pass rate, exceeds 70% target"** - POC success
