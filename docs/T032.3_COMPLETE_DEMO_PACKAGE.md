## ⚠️ What NOT to Demo

**Avoid these queries** (known failures from T032.2 testing):

❌ "Show me BMS network architecture" → 0 results  
❌ "HUMR-FOR-005" (alone in same chat) → context bleeding  
❌ "forms" (single word) → only 3 HUMR forms  
❌ "EN45545 requirements" → confusing (company vs hardware)

Use NEW chat for each scenario to avoid context bleeding!

## 💡 Demo Tips

### While Recording

**Visual Clarity**:
- Zoom browser to 110%
- Highlight key elements with cursor
- Pause to let results load fully
- Point out stars, percentages, boost indicators

**Pacing**:
- Read prompts aloud as you type
- Narrate what's happening during load time
- Use "Notice..." to direct attention
- Build excitement: "Now watch this..."

**Recovery**:
- If query fails → use backup prompt
- If slow → mention "analyzing 600+ docs"
- If unexpected → "Let's try this instead..."
- Keep calm, stay positive

### Ad-Lib Phrases

**During Load Time**:
- "Searching through 600+ documents..."
- "Analyzing across multiple departments..."
- "The LLM is synthesizing information..."
- "Notice how quickly it retrieves..."

**Highlighting Features**:
- "See those star ratings? That's our quality score."
- "72% with high confidence - much clearer than 0.723"
- "This would take hours manually"
- "All based on actual BMS documentation"

**Handling Questions**:
- "Great question! Let me show you..."
- "Actually, we tested that..."
- "Here's what we found in testing..."
- "Let me demonstrate..."
